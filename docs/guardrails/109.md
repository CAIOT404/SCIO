109. **Always** key a question to the owner by its attempt's thread id, never by `<feature>-a<attempt>`: attempts are numbered from 1 again in a new build thread and in a later milestone, so a reused id lets an old question's marker suppress a new post and an old answer answer a new question. **Never** let a failed GitHub post of the question channel halt the build: the feature stays parked, the failure is a ledger line, and the next pass posts it (ADR 0020, I-235).
