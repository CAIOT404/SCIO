17. **Always** make an edit whose text contains a backslash with the Edit or Write tool, never through a shell-embedded script; a script edit asserts its anchor count before it writes; a read-only one-liner with a regex counts too; a parallel agent's brief repeats this rule in its first lines; a batch of edits in which one has a backslash goes through the Edit tool whole, and a `\n` in the script's own string literals counts (I-071, I-072, I-112, I-117, I-131, I-157, I-162, I-167, I-176, I-177, I-191, I-203, I-207, I-212). Since issue #88 the push-gate hook refuses two kinds of command: a heredoc body or `python -c` script that holds a backslash, and any command with a double backslash, which the Bash tool halves before the shell runs (I-176). It cannot tell a mangled backslash from an intended one, so it refuses both, and such text goes through the file tools.
