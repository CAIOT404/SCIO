27. **Always** build the dashboard's web layer to end cleanly and to refuse what is not its own: a WebSocket handler reads the socket as well as writes it, so a closed tab ends it and the server can stop; a poll loop keeps one `receive()` alive for the connection and waits on it with a timeout, never cancelling a pending one, which can lose a disconnect; a server's graceful shutdown is bounded (`timeout_graceful_shutdown` for uvicorn), since on Windows a reset connection can hold `asyncio.Server.wait_closed` open forever; a WebSocket is accepted only from the server's own origin (the Origin's host and port equal the request's Host), and every response denies framing; and one unreadable source never fails an aggregate view: skip it, log it once per streak, and answer its own request with the reason. In its tests, give Starlette's `TestClient.websocket_connect` an absolute `ws://127.0.0.1/...` URL, since it ignores `base_url`, and never use Playwright's `wait_for_function` with a string predicate on a page whose CSP forbids eval: wait on a selector the page sets, or poll with `page.evaluate`; and never run the browser tests on the same runner as a CPU-bound parallel suite: `tests/live` has a CI shard of its own on few workers, or Chromium's fixed waits time out under the other workers' load (I-130, I-202, I-132, I-138, I-135, I-128, I-129, I-224).
