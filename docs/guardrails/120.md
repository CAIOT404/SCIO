120. **Never** count a feature as verified, or a milestone as delivered, while a test outside the acceptance directory skipped: a skip in the feature's own selector run fails its verify and names the skip and its reason, and the integration's `[test skips]` line is unmet at the milestone gate, which overrides a `pass` for a human. A skip elsewhere in the suite fails no feature (I-248).
