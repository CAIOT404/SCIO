107. **Never** stop the product build for a feature's design question. The attempt parks, the question goes to the feature's issue (offline, its issue file), and the milestone's other features keep building. The milestone waits, once, at `questions_wait`, and only when nothing else in it can build. Answers are read in a node that never interrupts, so a resumed stop always decides the feature it asked about. A failure without a question still stops for a decision (ADR 0020, I-235).
