69. **Always** resolve a program against the PATH of the environment it will run in, before spawning it. On Windows, CreateProcess searches the parent's PATH and ignores the PATH in the child's `env`. A supervisor started by Task Scheduler has no `sh`, so it could not start a replay's `sh scio.sh` (I-183). Guard: `symbol:resolve_program`, `test:test_a_program_on_the_child_envs_path_only_is_found`
