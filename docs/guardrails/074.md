74. **Always** run a child process that has a timeout through `scio.proctree.run_tree`, and turn what it raises into the caller's own failure kinds. `subprocess.run` kills only the first process at its timeout, so a child that held the pipes outlived it, and on Windows the unbounded drain made the timeout a hang.
