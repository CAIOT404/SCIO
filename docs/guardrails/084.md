84. **Always** close a ledger entry with its `- Resolved: <date or -> · Status: <status>` line. An entry without it is neither open nor resolved, and the guardrails check cannot ask it for a rule (I-204). A merge conflict can strip it too: git keeps a line both sides end with outside the conflict block, so check a resolved ledger before committing the merge (I-206). Guard: `check:check_ledger_statuses`, `test:test_every_ledger_entry_says_whether_it_is_open_or_resolved`
