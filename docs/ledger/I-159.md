### I-159 · Plan drift still flags a file the explorer named when the toolchain does not call it source
- Found: 2026-11-04 · issue #79, the S8 agent's report · `localized_files` keeps only `toolchain.is_source` files
- Symptom: none yet; for a python product, a T1 UI step whose explorer names `graphcalc/static/app.js` or `index.html` would still drift on them (the python profile's sources are `.py`), as P7 did on `cli.py`
- Root cause: the filter that keeps PRODUCT.md, README.md, pyproject.toml and progress.json out of `files_expected` is "source", and a python product's static assets are not source to the python profile. The filter's aim was to leave out docs, dependency files and SCIO's own bookkeeping; "source" left those out and also every non-code file a step may rightly change.
- Fix: the rule the owner approved with #104 (2026-11-18), in `scio/graph/nodes/planning.py`. `expected_for_its_step` decides: a tracked file the explorer named is expected for its step unless it is under `.scio/`, a docs file (`*.md`), or a dependency or lock file (`pyproject.toml`, `uv.lock`, `package.json`, `package-lock.json`, `requirements*.txt`). `localized_files` uses it, so `add_localized_files` and `keep_localized_files` add such files to every open step on T1. `is_source` no longer decides: `localized_files` still accepts the keyword and ignores it, and the two callers in `planning.py` stop passing it. `drifted_files`' test-file rule is unchanged. A checkpoint's stored `files_expected` is used as stored; the rule applies to plans made after it. The wider localized list also feeds `ground_plan`'s replacement rules 2 and 3 (the one localized file with the guess's basename, or in its directory), as source files already did.
- Sweep: `grep -rn "is_source" scio`. `aci/tools.py` (the syntax check of an edited file), `loop/impact.py` (a removed public `def` or `class`), `planning._repo_stats` and `intake_route` (the source-file count shown to the scoper and the router): each asks what is code, which is right there, and none decides what a plan expects. `grep -rn "is_source\|files_expected" docs`: guardrail 50 still says "the tracked source files the localize explorer found" (not #104's file; listed in its report).
- Guard: `test_a_static_asset_the_explorer_named_is_expected` (`static/app.js` named and touched: no drift; a file nobody named still drifts) and `test_docs_and_dependency_files_stay_out_of_expected_files` (`PRODUCT.md`, `pyproject.toml`, the lock files and `.scio/` named: still not expected, and drift flags them), in `tests/unit/test_old_ledger_entries.py`. Both pass the python profile's `is_source` and failed on the old code (`assert [] == ['graphcalc/static/app.js']`). Guardrail 122.
