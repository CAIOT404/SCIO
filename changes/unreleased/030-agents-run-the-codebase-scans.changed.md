An agent's checks run the tests that scan the whole codebase (I-234, issue #141). A new pytest marker, `scan` ("scans the whole codebase for a forbidden construct"), marks the 11 tests that walk `scio/`, `scripts/`, `recovery/`, `evals/` or `tests/` for a construct, and `.claude/templates/agent-brief.md`'s checks add `uv run python -m pytest -q -n 4 -m scan` after the agent's own test files. `tests/unit/test_scan_marker.py` fails when the template loses that line or when a test that calls `rglob` or `os.walk` on a path built from the repository root has no `scan` marker.
