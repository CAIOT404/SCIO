Claude Code worker turns now show in the traces, and every model call's span carries its thread id ([docs/OBSERVABILITY.md](docs/OBSERVABILITY.md), issue #102). With `SCIO_WORKER_BACKEND=claude_code`, each turn SCIO accounts (a coder, debugger, documenter or explorer turn, and its resumed summary call) emits one `invoke_agent <role>` span, backdated by the turn's API time, with the role, provider, model, token and cache counts, `scio.usd` and the tags, as an API turn's span has (I-122). Before, those turns were in the cost ledger only. The tools still run inside the `claude` binary, so they still have no `execute_tool` spans. Every `invoke_agent` span whose call is tagged with a thread now sets `scio.thread_id` beside `scio.tag.thread`; the attribute was declared and never set (I-123). A tracing failure is logged and never fails the turn.
