The merge stop of a product build lists each integration check's verdict. `scio build` prints one line per check before the stop's JSON (`[tests] passed: 231 passed, 1 skipped`), and the stop's payload carries the same list as `checks` (`name`, `verdict`: `passed`, `FAILED` or `skipped`, and a one-line `detail`). The release stop carries it too, and the milestone PR's "Test evidence" section opens with the same lines from the same function, above the raw report. Before, the verdict lines existed only in the PR body, where a long test output could cut the last ones off. A build paused at a merge stop before this change resumes as before (#156).
