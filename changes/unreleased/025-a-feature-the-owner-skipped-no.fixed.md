A feature the owner skipped no longer stops the build a second time at the milestone gate. The gate's input names it as deferred by the owner, with no criteria to judge (gate prompt v2), and a passing verdict on green checks goes on to the milestone PR. A feature that failed, never ran or stopped without the owner's `skip` still stops the gate, and so does a milestone whose every feature was skipped. graphcalc M4 paused at the gate after the owner had already skipped P29 (issue #140, I-230).
