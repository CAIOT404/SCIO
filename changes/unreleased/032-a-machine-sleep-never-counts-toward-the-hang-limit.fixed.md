The recovery supervisor's hang limit counts only its own awake time, so a machine sleep never counts toward it. It used to measure silence by the wall clock, so the first poll after a laptop slept longer than `hang_after_s` killed a healthy build as hung and opened a repair. That happened to graphcalc's replay on 2026-11-17 after a 29-hour sleep (#158). A gap between two polls more than 60 s longer than `poll_s` now counts as one poll, and a child that stays silent once the machine is awake is still killed after `hang_after_s` (I-239).
