A feature whose own tests skipped is no longer verified, and a milestone with skipped tests no longer passes its gate on its own (issue #169, part B; I-248). In verify, a run of the feature's own tests that passed with a `skipped (not verified)` line fails as a test failure: the feature's test output keeps the skip and its reason, and adds a hint telling the coder to make the test run (import what it needs plainly, or remove the skip). The whole-suite run still accepts skips, so a skip elsewhere fails no feature, and an acceptance test's skip is never reported. At the milestone gate, the integration's `[test skips]` line is listed as unmet, and a `pass` verdict becomes `escalate_human` with the reason `tests skipped outside tests/acceptance: ...`; the owner can still answer `proceed`.
