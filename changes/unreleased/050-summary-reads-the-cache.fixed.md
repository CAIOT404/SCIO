The Claude Code worker's closing summary reads the session's prompt cache instead of writing the whole session to it again. That write was about 15% of a feature's cost at API prices (issue #185, I-250). The `--resume` call keeps the session's tool list, with no `--tools ""` and no `--json-schema`. The schema travels in its prompt, and SCIO parses and validates the reply's JSON. `--permission-mode dontAsk` keeps any tool call from editing, even when the settings' default mode is `auto`. Live probe: a plain summary, before the mode flag was added, read 28,144 tokens and wrote 1,078, where the old call read none and wrote 12,790. The final call, told to Write first, read 62,698 and wrote 1,452, and the Write was denied.
