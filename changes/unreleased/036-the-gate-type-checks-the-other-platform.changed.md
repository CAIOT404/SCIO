The local gate type-checks the other platform too. Right after `mypy` it runs a second step, `mypy-linux` (`mypy --platform linux`) on Windows and `mypy-win32` elsewhere, in every mode that runs mypy, with its own cache in `.mypy_cache/other-platform` so the two runs do not invalidate each other (about 1 s more when warm, 11 s the first time). Before, the gate checked only the platform it ran on, and code after `if sys.platform != "win32": return` passed locally and failed CI's Linux run with "Statement is unreachable" (I-241).
