The agent brief states four edge decisions before it is sent. `.claude/templates/agent-brief.md` has a section "Edge decisions (decided before sending)": Identity (is every id, key or file name unique across threads, milestones and reruns), Failure (what happens when an external call or write fails), Resume (what a rerun or a record stored before the change does) and Pins (the tests outside the owned files that pin the behaviour). `scripts/brief.py` fills Pins itself, with each test file's reason, and adds those files to the brief's checks command; the other three stay a `TODO` for the orchestrator. `uv run python scripts/brief.py --check FILE` exits 1 and names each `TODO` left (line number and section), and exits 0 when there is none. The agent report has an `edge_decisions` field. Before, 7 of 9 builder agents in one session needed a second round for one of these four cases.
